# CloudClaude

## Overview
Cloud-hosted assistant with Feishu integration and a Next.js admin UI.

## Tech Stack
- TypeScript
- Node.js 18+
- Express
- Next.js 14

## Structure
- src/: backend source
- config/: configuration files
- data/: runtime data
- frontend/: Next.js UI

## Commands
- npm run dev
- npm run build
- npm run start

## Notes
- Do not commit real credentials.
- Keep logs in logs/.
